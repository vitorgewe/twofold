# M4 Safety and delivery

## Goal

The user's data is protected by backups, the history from the old app can be imported, and the app can be reached from a URL and released with a version.

## Acceptance criteria

- [ ] A backup file exported on one browser profile restores net worth and transaction count exactly in a fresh profile
- [ ] A CSV in the documented format imports all or nothing, and importing the same file twice adds nothing
- [ ] Settings shows the app version
- [ ] The two delivery tasks stay `blocked` with their reasons until the author provides the Expo account and token
