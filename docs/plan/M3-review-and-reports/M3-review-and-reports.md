# M3 Review and reports

## Goal

The user can browse, edit and delete past transactions without ever unbalancing the books, keep exchange rates up to date, and read an income statement for any period.

## Acceptance criteria

- [ ] The transaction list filters by period and account, and a transaction opens in a detail view
- [ ] Editing a transaction is only possible while it stays balanced, and deleting removes all its postings
- [ ] Rates can be entered, are listed with their age, and prefill foreign-currency postings; saving a rate never changes net worth
- [ ] The income statement shows income, expenses and result for this month, last month, this year and a custom range
- [ ] All screens work at 390 x 844 with no clipped text and no horizontal scroll
